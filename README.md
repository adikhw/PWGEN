# PWGEN: Password Generator + Validator

PWGEN adalah aplikasi terminal (CLI) berbasis Python yang punya dua fungsi:

1. **Generator:** membuat password acak dengan panjang dan jenis karakter pilihan sendiri (huruf kecil, huruf besar, angka, simbol), memakai modul `secrets`.
2. **Validator:** menilai kekuatan sebuah password (lemah / sedang / kuat) beserta alasannya.

Project ini dibuat sebagai bahan belajar Python (string, `secrets`, regex dasar, dan tipe data). Hanya memakai modul bawaan Python, tanpa library eksternal. Password tidak pernah disimpan ke file maupun log.
